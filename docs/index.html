The Walt Disney Company

$119.65

NYSE: DIS · 2026年11月11日收盘价

(长期优质资产，估值需要安全边际)

迪士尼是我认为非常值得长期研究的一家消费娱乐公司。

但我想先给出一个核心判断：

迪士尼真正的价值不是电影，而是IP（知识产权）商业化能力。

米老鼠、漫威、皮克斯、星球大战等IP，可以不断通过电影、流媒体、主题乐园、玩具、授权商品实现变现。

这是一种非常有价值的商业模式。不过，迪士尼目前面临的问题是：IP很强，但传统电视业务承压，流媒体竞争激烈，主题乐园需要持续投入大量资本。

我的分析周期：3–5年，以巴菲特、段永平式的商业模式、护城河、自由现金流和安全边际作为主要判断标准。

  • 迪士尼真正值得关注的是未来3–5年利润能否持续增长。

二、迪士尼到底靠什么赚钱？

迪士尼的商业模式可以理解为：创造IP，然后通过不同渠道重复收钱。

1. Experiences：主题乐园、邮轮、度假村

这是迪士尼最重要的现金流发动机之一，包括迪士尼乐园、度假村、邮轮及相关消费品。

(核心护城河)

2. Entertainment：电影、电视、流媒体

包括迪士尼电影、漫威、皮克斯、星球大战、Disney+、Hulu，以及内容授权。

(IP价值核心)

3. Sports：体育媒体

主要包括ESPN体育赛事版权、电视订阅和广告收入。

(面临结构性转型)

三、三个业务哪个最赚钱？

根据2026财年第三季度（截至2026年6月27日）的财报：

业务单季度营收单季度营业利润营业利润率
Entertainment113.45亿16.80亿14.8%

美元；营业利润率为营业利润÷业务营收，四舍五入。

这里有一个非常重要的发现：

主题乐园业务才是迪士尼最有价值的利润来源之一。

单季度主题乐园及体验业务贡献30.17亿美元营业利润，超过娱乐业务和体育业务。

而且该业务同比营业利润增长20%。

这意味着迪士尼并不是单纯依赖电影票房的公司，而是一家拥有强大线下消费场景的IP公司。

四、迪士尼的护城河有多深？

我从价值投资角度，把护城河拆成五个部分。

护城河强度我的评价
IP资产极强米老鼠、漫威、皮克斯等
品牌影响力极强全球消费者认知
主题乐园极强高投入、高体验壁垒
内容制作能力强但存在爆款不确定性
流媒体平台中等Netflix、Amazon竞争

1. IP是迪士尼最核心的资产

迪士尼的IP与普通影视公司最大的区别：

普通电影公司拍完电影，主要通过票房和版权赚钱。

迪士尼可以把一个IP变成：

  • 电影票房。
  • Disney+订阅。
  • 主题乐园门票。
  • 玩具、服装、周边商品。
  • 游戏授权。
  • 品牌授权。
  • 邮轮及度假体验。

例如漫威，一个成功的角色可以持续商业化十几年甚至几十年。

这就是IP的复利效应。

但是有一个问题：IP不是永远有价值的。

如果创作质量下降，消费者对角色失去兴趣，IP也会贬值。

2. 主题乐园是非常难复制的资产

为什么我特别看好迪士尼主题乐园？

因为它同时拥有：

  • 品牌。
  • 土地与基础设施。
  • 娱乐内容。
  • 运营能力。
  • 家庭消费场景。
  • 全球旅游吸引力。

竞争对手可以建游乐园，但很难复制迪士尼几十年积累的IP和体验体系。

而且消费者愿意为家庭体验支付溢价。

从长期投资角度，我认为这比单纯投资一家电影制作公司更有吸引力。

3. Disney+是否能够打败Netflix？

Disney+

IP资源丰富，拥有漫威、皮克斯、星球大战等内容。

Netflix

全球化运营、内容分发、推荐算法和订阅商业模式成熟。

我的判断：

比较维度迪士尼Netflix
IP储备更强相对较弱
原创内容强强
主题乐园有无
全球订阅运营仍在发展更成熟
用户粘性强强
业务多元化更强相对集中

我不认为迪士尼必须打败Netflix才能成功。

迪士尼更好的战略应该是：

让流媒体成为IP商业化的入口，而不是把所有资源都投入到订阅用户数量竞争中。

我最关注三个问题

第一：自由现金流。

迪士尼经营现金流约169.9亿美元，但资本开支达到87亿美元。

说明主题乐园、邮轮、影视制作等业务需要持续投入。

这是一个需要特别关注的地方。

第二：ROIC只有7.11%。

这个数字并不理想。

如果一家公司的资本回报率长期低于资本成本，就算营收增长，也未必能创造真正的股东价值。

第三：负债。

指标数值

迪士尼的负债并没有达到无法承受的程度，但它也不是一个轻资产、低负债的企业。

我希望未来看到自由现金流增长快于债务增长。

六、未来3–5年的增长动力

我认为未来迪士尼主要有四个增长引擎。

增长方向重要性未来看点
主题乐园极高提价、游客消费、扩建
流媒体高盈利能力、订阅收入
IP电影高漫威、皮克斯、星球大战
体育媒体中等ESPN数字化转型

1. 主题乐园继续扩张

主题乐园是我最看好的业务。

未来增长不一定需要游客数量大幅增长，也可以通过：

  • 提高门票价格。
  • 提高酒店入住率。
  • 提高餐饮和商品消费。
  • 增加邮轮航线。
  • 提升游客平均消费。

但要警惕过度投资：乐园扩建会增加折旧和资本开支，不能只看收入增长。

2. 流媒体从烧钱转向赚钱

迪士尼需要证明Disney+能够持续产生利润，而不仅仅是增加订阅人数。

如果流媒体可以形成稳定盈利，迪士尼整体估值有机会获得提升。

3. IP重新进入高质量创作周期

我认为这是迪士尼最大的潜在催化剂。

如果未来几年漫威、皮克斯、星球大战能够重新推出高质量作品，就可能同时推动电影票房、流媒体和周边授权收入。

但这件事有较大的不确定性。

4. 管理层与资本配置

迪士尼目前CEO为鲍勃·艾格（Bob Iger）。

我对艾格的评价：

优点：

  • 熟悉迪士尼的IP商业模式。
  • 具有大型娱乐资产收购和整合经验。
  • 能够理解电影、主题乐园和媒体业务之间的协同。

不足：

  • 迪士尼此前经历了流媒体战略调整和组织重组。
  • 内容业务的长期竞争力仍需要验证。
  • CEO交接和接班人安排是重要的不确定因素。

我不会仅仅因为艾格曾经创造过辉煌，就给予公司更高估值。

真正重要的是未来几年资本回报率和自由现金流能否改善。

4. 分批买入价格

我更看重安全边际，而不是预测短期股价。

股价区间操作逻辑
$110–120观察接近合理价值
$100–110小仓买入开始出现安全边际

$80–90积极研究加仓前提是基本面没有恶化
$80以下重新评估可能存在重大经营问题

如果我的估值中枢是120美元，那么100美元买入相当于约17%的折价，90美元则约25%的折价。

我个人更倾向于等待100美元以下，而不是在120美元附近追买。

这里的价格区间建立在公司盈利预测没有明显下修的前提上。

我特别提醒一个问题：

不要把迪士尼的IP护城河理解成永远不会衰退。

可口可乐的品牌消费习惯相对稳定，而迪士尼需要持续创造新的优秀内容。

这两种护城河并不完全相同。

十二、如果从巴菲特、段永平的角度看

我认为迪士尼有三个非常明显的优点：

  • 品牌和IP： 可以反复创造收入，具有长期商业价值。
  • 消费者定价权： 主题乐园和周边产品拥有一定溢价能力。
  • 商业生态： 一个IP可以通过多个业务渠道反复变现。

但是它也有三个明显缺点：

  • 内容创作存在很大的不确定性。
  • 资本开支比较大。
  • ROIC目前不够优秀。

我认为迪士尼属于一家拥有优秀资产，但经营质量仍有提升空间的公司。

如果把它与Netflix、任天堂、索尼放在一起，我会特别关注它的IP商业化效率。

最后，我想强调一个投资判断

如果让我在迪士尼和Netflix之间选择：

  • 我更喜欢迪士尼的实体IP资产和主题乐园护城河。
  • 我更认可Netflix目前的流媒体运营能力。
  • 我不会因为迪士尼拥有更多IP，就认为它一定比Netflix更值得投资。

迪士尼值得长期研究，但目前我更愿意等待更好的买入价格。

另外，下一步最值得做的是把迪士尼和你此前研究过的NFLX、任天堂、SONY放在一起比较，重点比较：

  • 过去10年净利润率。
  • ROIC。
  • 自由现金流。
  • IP商业化能力。
  • 未来5年EPS增长。
  • 合理买入价和预期年化回报。

这样才能判断哪家公司真正拥有更好的长期复利能力。
